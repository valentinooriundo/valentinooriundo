# 📂 Project Philosophy

Every major project in this GitHub should answer six questions:

```text
1. What business problem am I solving?

2. What data am I using?

3. How did I clean and prepare the data?

4. What did I discover?

5. How did I communicate the results?

6. What business decision could be made?
```

A project is not finished when the code runs.

A project is finished when the analysis provides **useful information for decision-making**.
